ESP32-S3-Touch-LCD-7 – PCB Manufacturing Files

This repository contains the complete manufacturing files for the custom PCB designed for the ESP32-S3-Touch-LCD-7 project.

The files can be used to manufacture the PCB using services such as JLCPCB or PCBWay.

Gerber files

Instructions

Download the ZIP archive containing the PCB manufacturing files and upload it to your preferred PCB manufacturer.

All original manufacturing files are provided without modification.
